# 001 — 헤드리스 Shopify 아키텍처

## 결정
기존 MakeShop 쇼핑몰을 **Shopify 헤드리스 구조**로 이전한다.
프론트엔드는 Next.js로 새로 만들고, Shopify는 상품·주문 데이터의 백엔드로만 사용한다.

## 배경
- 기존 MakeShop 기반 사이트는 프론트엔드 커스터마이징과 다국어(ko/ja) 대응에 제약이 컸다.
- 인스타그램 유입 → 모바일 구매로 이어지는 흐름을 매끄럽게 설계해야 했다.
- Meta CAPI 같은 서버 측 전환 추적을 직접 붙일 필요가 있었다.

## 대안
- **MakeShop 유지 + 테마 커스터마이징**: 프론트 자유도·다국어·추적 한계로 제외.
- **Shopify 기본 테마(Liquid)**: 백엔드는 안정적이나 프론트 표현·추적이 제한적.

## 이유
- Storefront API로 상품 데이터를 가져오면서 프론트는 Next.js로 완전히 자유롭게 구성.
- `@inContext` 지시어로 locale별 상품 데이터를 깔끔하게 받을 수 있음 (다국어).
- 서버 컴포넌트에서 데이터를 미리 채워 SEO·초기 로딩에 유리.

## 트레이드오프
- 프론트·결제·주문 흐름을 직접 구현해야 해서 초기 구현량이 많다.
- Shopify 테마의 기성 기능(장바구니 등)을 직접 만들어야 한다.
