# 운영 워크플로우 파악 체크리스트

> 배송팀 인터뷰 답변을 수집하고,  
> 수집된 내용을 바탕으로 Shopify 연동 설계에 반영한다.

---

## 현재 사용 중인 시스템 (확인 완료)

| 시스템 | 역할 |
|---|---|
| **메이크샵** | 쇼핑몰 주문 관리, 주문 취소, 재고 관리, 품절 처리 |
| **위드유** | 송장 발행 프로그램 (우체국 택배) |
| **셀메이트** | 재고 수량 파악 |

> ⚠️ 세 시스템 모두 메이크샵 중심으로 연결돼 있음.  
> Shopify 전환 시 세 군데 모두 재연동 또는 대체 필요.

## 2. 반품 흐름

### 확인 완료
```
고객 반품 접수 (메이크샵 CS 게시판)
    ↓
CS 담당자 확인 → 배송팀에 CSV 파일 전달
    ↓
배송팀이 CSV 내 송장번호를 위드유에 붙여넣기 → 반품 수거 신청
    ↓
우체국 기사님이 고객 물건 수거
    ↓
배송팀 → CS 담당자에게 수거 완료 알림
    ↓
CS 담당자가 환불 처리
```

- [x] 반품 접수 창구: 메이크샵 CS 게시판
- [x] 수거 방식: 우체국 기사 방문 수거
- [x] 수거 예약: 위드유에 송장번호 붙여넣기로 처리
- [x] 환불 처리: CS 담당자가 직접

### ⚠️ Shopify 이전 시 필요한 것
- [ ] `/admin/returns` 페이지에 **CSV 다운로드** 기능 추가  
  _(현재 없음 — CS 담당자가 배송팀에 파일 전달할 방법이 없음)_
- [ ] CSV 필수 필드: 주문번호, 고객명, 연락처, 주소, 반품사유, 반품상품
- [ ] 환불 처리: 메이크샵 PG → 토스 대시보드로 변경 (토스 계약 후)

### 아직 미확인
- [x] 반품 승인 기준: CS 담당자 재량, 웬만하면 승인
- [x] 검수 방식: 사진 + 실물 병행
- [x] 환불 완료 알림: 현재 없음
- [x] → **요청**: 환불 완료 시 카카오톡 or 이메일 자동 안내 원함

## Shopify 전환 시 영향 분석

| 항목 | 현재 | 전환 후 | 이슈 |
|---|---|---|---|
| 주문 관리 | 메이크샵 | Shopify Admin | 배송팀 교육 필요 |
| 위드유 연동 | 메이크샵 → 위드유 | Shopify 엑셀 → 위드유 | 방식 동일, 경로만 변경 |
| 재고 관리 (WMS) | 셀메이트 + 전용 스캐너 | Shopify 바코드 앱 + 스캐너 호환 필요 | **전용 기기 호환 여부 확인 필수** |
| 품절 처리 | 메이크샵 | Shopify Admin | 배송팀 교육 필요 |
| 주문 취소 | 메이크샵 | Shopify Admin | 배송팀 교육 필요 |
| 환불 처리 | 메이크샵 PG 연동 | 토스 대시보드 or API | 토스 계약 후 확인 |
