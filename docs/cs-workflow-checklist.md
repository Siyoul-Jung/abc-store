# CS 워크플로우 체크리스트 (1:1 문의 게시판)

> 현재 알고 있는 것과 미확인 사항을 구분해 정리.  
> Shopify 이전 후 CS 운영 설계의 기준 문서.

---

## 채널 정책 (확정)

- [x] CS 채널: **Q&A 게시판 단일 채널** (`/qa`)
- [x] 이메일·채널톡·카카오 등 외부 메신저 미사용
- [x] 로그인 필수 (비로그인 접근 불가)
- [x] 1:1 문의 전용 (공개 게시판 아님, 타인 문의 열람 불가)

---

## 문의 분류 체계 (확정)

| 카테고리 | 처리 방식 |
|---|---|
| 배송 | Q&A 답변 |
| 교환/반품 | `/returns` 폼으로 자동 리다이렉트 |
| 불량/오배송 | `/returns` 폼으로 자동 리다이렉트 |
| 환불 | Q&A 답변 (환불 상태 조회용) |
| 상품 | Q&A 답변 |
| 기타 | Q&A 답변 |

---

## 현재 구현된 것

- [x] 고객 문의 작성 (`/qa/new`) — 로그인 필수, 주문 드롭다운 연동
- [x] 내 문의 목록 (`/qa`) — 본인 문의만 표시
- [x] 문의 상세 (`/qa/[id]`) — 본인만 접근 가능
- [x] 어드민 문의 목록 (`/admin/qa`) — 상태·카테고리 필터
- [x] 어드민 답변 작성 (`/admin/qa/[id]`) — 템플릿 선택 + 직접 작성
- [x] 새 문의 → 어드민 이메일 알림 (Resend 연동 시 작동)
- [x] 답변 등록 → 고객 이메일 알림 (답변 내용 미포함, 링크만)
- [x] 고객 Shopify 주문 내역 연동 (문의 작성 시 주문 선택)

## 운영 정책 — 미확인

### 응답 시간
- [ ] 답변 목표 시간(SLA)이 있나요? (예: 24시간 이내)
- [ ] 운영일/운영시간이 정해져 있나요? (주말·공휴일 포함 여부)

### 담당자
- [ ] CS를 전담하는 담당자가 있나요, 공동 처리인가요?
- [ ] 어드민 계정을 여러 명이 쓰나요?

### 답변 템플릿
- [ ] 현재 자주 쓰는 답변 유형이 있나요? (배송 지연, 사이즈 문의 등)
- [ ] 템플릿을 미리 등록해둘 예정인가요?
- [ ] 누가 템플릿을 관리하나요?

### 에스컬레이션
- [ ] 고객이 답변에 불만족할 경우 어떻게 처리하나요?
- [ ] CS로 해결 안 되는 케이스 (예: 법적 분쟁)는 어떻게 하나요?

## 카테고리별 처리 흐름 — 미확인

### 배송 문의
- [ ] 배송 조회는 어드민이 Shopify 주문에서 직접 확인하나요?
- [ ] 배송 지연 기준이 있나요? (발송 후 며칠 이상이면 지연?)
- [ ] 고객 요청 시 주소 변경이 가능한 시점이 언제까지인가요?

### 환불 상태 문의
- [ ] 환불 카테고리로 문의가 오면, `/admin/returns`에서 상태 확인 후 답변하는 방식인가요?
- [ ] 환불 완료 후에도 문의가 오면 어떻게 처리하나요?

### 상품 문의
- [ ] 재고 확인 요청이 오면 어떻게 처리하나요?
- [ ] 입고 일정 문의는 어떻게 답변하나요?

## 시스템 — 미완성

| 항목 | 상태 | 비고 |
|---|---|---|
| 새 문의 어드민 알림 이메일 | ⚠️ 로컬 준비 완료 | Vercel 환경변수 등록 필요 |
| 답변 알림 이메일 (고객) | ⚠️ 로컬 준비 완료 | Vercel 환경변수 등록 필요 |
| 답변 템플릿 데이터 | ❌ 비어있음 | Supabase `answer_templates` 테이블에 등록 필요 |
| 카카오 알림톡 | ❌ 미구현 | 런칭 후 추가 예정 |
