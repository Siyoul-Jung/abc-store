## 2. 반품·교환·환불 처리 연습

고객 입장 → 관리자 입장을 한 번씩 돌려봅니다.

**(고객) 반품 신청** — `/ko/returns`
- 주문번호 `#1037`, 고객명 `김반품` 입력 → 조회 → 반품 상품 선택 → 사유/계좌 입력 → 신청

**(관리자) 반품 처리** — `/admin/returns`
- 접수된 건 확인 → **수거 승인 → 물건 수령 확인 → 환불 처리** 순서로 진행
- 환불 금액 계산(단순반품 −7,000원 / 불량은 전액)이 자동 표시되는지 확인
- 카드 자동환불은 토스 실계약 후 동작 — 지금은 "수동환불 완료" 경로로 연습

**교환(#1038)**: 우리 정책상 "반품 후 재구매" 안내(템플릿 5번). 반품 흐름과 동일.
**불량(#1039)**: 전액 환불 + 회수비 미부과로 처리되는지 확인.
