# 디자인 레퍼런스 분석 — 유니클로 채용 사이트

> 참조: https://bethegloballeader.co.kr/ (UNIQLO 2026 채용 캠페인 마이크로사이트)
> 작성: 2026-06-03 · **분석 전용 문서 (코드 변경 없음)**
> 목적: 레퍼런스의 "고급스러운" 디자인 원칙을 추출해 abc-store 홈에 적용할 개선 포인트 정리

---

## 1. 레퍼런스가 "비싸 보이는" 이유 (핵심 원칙)

패션 브랜드 사이트의 프리미엄 감각은 **화려함이 아니라 절제**에서 나온다.

1. **과감한 여백** — 섹션 간 큰 패딩으로 콘텐츠가 숨 쉴 공간을 줌
2. **큰 이미지가 주인공** — 글자는 최소, 사진/룩북이 화면을 지배
3. **강한 헤드라인 한 줄** — Hero에 브랜드 메시지를 크게 ("옷의 힘으로 세계를 더욱 풍요롭게")
4. **세로 스크롤 내러티브** — 섹션을 블록 단위로 끊고 이름을 붙여(FR WAY, ENJOY YOUR LIFE) 리듬감
5. **중성 베이스 + 한 포인트 컬러** — 흑백/뉴트럴에 액센트 1개 (무인양품·아페쎄 공식)
6. **점진적 노출** — 스크롤하며 콘텐츠가 fade/slide-up 으로 등장

> abc-store는 이미 `surface`(크림 #FAF7F3) + `coral` 포인트 토큰을 갖고 있어
> **"중성 베이스 + 한 포인트"** 공식에 구조적으로 잘 맞는다.

## 2. 레퍼런스 섹션 구조 (위→아래)

| # | 섹션 | 성격 |
|---|---|---|
| 1 | Sticky 네비 + "접수하기" CTA | 고정 네비, 항상 CTA 노출 |
| 2 | **Hero** (풀블리드 이미지 + 헤드라인) | 브랜드 미션 한 줄 |
| 3 | FR WAY (철학) | 텍스트 중심, 이미지 ~5% |
| 4 | 인재상 "BELIEVE IN YOUR POTENTIAL" | 메시지 박스 5개 |
| 5 | UNIQLO 6개 키워드 그리드 | 아이콘 기반 |
| 6 | 커리어 패스 (세로 플로우차트) | 이미지 ~30% |
| 7~9 | 자격/설명회/복지 (아이콘 9개 그리드) | 정보 + 아이콘 |
| 10 | 직원 인터뷰 "LIFE AT UNIQLO" | 4컬럼 사진 + 영상 |
| 11 | **CTA 풋터 밴드** (버튼 3개) | "이제 당신의 가능성을…" |
| 12 | 저작권 풋터 | |

핵심 패턴: **Hero(메시지) → 여러 내러티브 섹션 → 강한 CTA 밴드 → 풋터**

## 3. abc-store 현재 홈 구조

`app/[lang]/(store)/page.tsx` 기준:

| # | 섹션 | 파일 | 상태 |
|---|---|---|---|
| 1 | Hero (이미지 캐러셀 3장) | `components/home/Hero.tsx` | ⚠️ **텍스트 없음** |
| 2 | ProductGrid (신상 6개) | `components/home/ProductGrid.tsx` | OK |
| 3 | InstagramFeed (3×3) | `components/home/InstagramFeed.tsx` | OK |

→ 섹션 3개. **브랜드 메시지·카테고리 진입·룩북·CTA 밴드가 없다.**

## 4. 격차(Gap) & 개선 제안 — 우선순위순

### 🔴 P1. Hero 헤드라인이 표시되지 않음 (최우선)
- **현상**: `Hero.tsx`가 `season`/`tagline`/`ctaLabel` props를 받지만 **렌더링하지 않음**. 순수 이미지 캐러셀.
- **레퍼런스**: 이미지 위에 브랜드 메시지 한 줄 + CTA 버튼.
- **제안**: 이미 넘어오는 `dict.home.tagline`을 이미지 위에 큰 타이포로 오버레이 + "신상 보기" CTA 버튼. 데이터가 이미 있어 **비용 최소, 효과 최대**.
- **모바일 주의**: Hero 높이가 모바일 `32vh`로 낮음 → 텍스트 얹으려면 높이/가독성(어두운 그라데이션) 재검토 필요.

### 🟠 P2. 카테고리 진입 동선 부재
- **레퍼런스**: 명확히 구획된 섹션으로 다음 행동 유도.
- **현상**: 홈에서 컬렉션(new/kids/adult/sale)으로 가는 시각적 진입점이 약함.
- **제안**: Hero 아래 **카테고리 타일 2~4개**(KIDS / ADULT / NEW / SALE) — 큰 이미지 + 라벨. 모바일 가로 스크롤 or 2열 그리드.

### 🟠 P3. 브랜드 스토리 섹션 부재
- **레퍼런스**: FR WAY(철학) 같은 "왜 이 브랜드인가" 블록.
- **제안**: 신상 그리드와 인스타 사이에 **짧은 브랜드 스토리 밴드**(이미지 1 + 카피 2~3줄 + "ABOUT →"). 이미 `/about` 페이지 존재 → 그 입구 역할.

### 🟡 P4. 섹션 리듬 & 여백
- **레퍼런스**: 섹션마다 넉넉한 상하 패딩 + 배경색 교차(흰↔뉴트럴)로 리듬.
- **제안**: 홈 섹션을 `cream`↔`white` 교차 배경으로 구분, 상하 패딩 키우기. 섹션 제목 타이포(Poppins) 크게.

### 🟡 P5. 스크롤 인 애니메이션
- **레퍼런스**: 콘텐츠가 스크롤 시 서서히 등장.
- **제안**: 섹션/카드에 fade + slide-up (IntersectionObserver 또는 CSS `@starting-style`). 과하지 않게 1단계만.

### 🟢 P6. CTA 풋터 밴드 (선택)
- **레퍼런스**: 풋터 직전 강한 행동 유도 밴드.
- **제안**: 인스타 피드 아래 "지금 신상 만나보기" 밴드 → 컬렉션/전체상품으로. (쇼핑몰이라 우선순위는 낮음)

---

## 5. 적용 시 지킬 제약 (프로젝트 규칙)

- `tailwind.config` 만들지 말 것 — `globals.css`의 `@theme` 사용
- 색은 기존 토큰(`cream`/`coral`/`ink`/`citrus`) 안에서 — 새 색 남발 금지
- **모바일 우선 검증** — 발견(인스타)→탐색→구매 흐름이 끊기지 않게
- 서버 컴포넌트에 불필요한 `'use client'` 금지 (애니메이션 필요한 부분만 클라이언트 분리)

---

## 6. 권장 진행 순서 (착수 시)

1. **P1 Hero 헤드라인** — 가장 작고 효과 큼 (반나절)
2. **P2 카테고리 타일** — 구매 동선 직접 개선
3. **P4 여백/리듬** — 전체 톤 업
4. **P3 브랜드 스토리** → **P5 애니메이션** → **P6 CTA 밴드**

> 레퍼런스는 **채용 사이트**라 장바구니·결제 동선이 없다.
> 통째로 모방하지 말고 **"분위기·레이아웃 원칙"만 추출**해 쇼핑 동선 위에 입힐 것.
