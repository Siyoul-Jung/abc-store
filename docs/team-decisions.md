# applebuttercollege — 팀 논의 및 결정 사항

> 사이트 구축(개발) 외에 팀 내부적으로 논의하고 결정해야 할 사항 정리.  
> 결정된 항목은 ✅ 표시, 미결 항목은 ⬜ 표시.

---

## 1. 한국 — MakeShop → Shopify 전환 체크리스트

> 기존 메이크샵 사이트의 운영 정책을 Shopify로 이전 시 확인/세팅이 필요한 항목.  
> 정책 자체는 기존과 동일하게 가져가되, Shopify 환경에 맞게 재설정 필요.

### 1-1. 전환 시점 결정
| 항목 | 내용 | 상태 |
|---|---|---|
| 전환 목표일 | 메이크샵 운영 종료 → Shopify 전환 일정 확정 | ⬜ |
| 기존 고객 공지 | 사이트 이전 안내 방법 및 시점 (이메일, SNS 등) | ⬜ |
| 병행 운영 여부 | 전환 기간 중 두 사이트 동시 운영 여부 | ⬜ |
| 기존 주문/고객 데이터 | 메이크샵 주문 이력, 회원 데이터 Shopify 이전 여부 | ⬜ |

### 1-2. Shopify 운영 세팅
| 항목 | 내용 | 상태 |
|---|---|---|
| 주문 확인 이메일 | Shopify 자동 발송 이메일 템플릿 한국어 커스터마이징 | ⬜ |
| 배송 안내 이메일 | 운송장 번호 등록 및 발송 방식 (메이크샵과 동일하게 유지 여부) | ⬜ |
| 재고 알림 기준 | Shopify 재고 부족 알림 임계값 설정 | ⬜ |
| 품절 상품 처리 | 숨김 처리 vs 품절 표시 유지 정책 | ⬜ |

### 1-3. 광고 / 마케팅 전환
| 항목 | 내용 | 상태 |
|---|---|---|
| Meta 픽셀 도메인 변경 | 기존 메이크샵 도메인 → applebuttercollege.com 으로 픽셀 도메인 변경 | ⬜ |
| CAPI 전환 | 픽셀 → CAPI로 전환 후 기존 광고 캠페인 성과 데이터 연속성 확인 | ⬜ |
| UTM 파라미터 | 기존 광고 링크 URL 업데이트 (새 도메인으로) | ⬜ |

### 1-4. SEO / URL 전환
| 항목 | 내용 | 상태 |
|---|---|---|
| 기존 URL 리다이렉트 | 메이크샵 상품 URL → Shopify URL 301 리다이렉트 처리 | ⬜ |
| 검색 노출 유지 | Google Search Console 도메인 변경 등록 | ⬜ |

## 2. 일본 런칭 전 결정 사항

### 2-1. 배송 / 물류
| 항목 | 내용 | 상태 |
|---|---|---|
| 배송사 선택 | EMS(우체국), DHL, FedEx 중 계약 배송사 | ⬜ |
| 배송비 정책 | 엔화 기준 요금표 및 무료배송 임계값 | ⬜ |
| 관세 처리 방식 | DDP(판매자 부담, 소비자 편의) vs DDU(소비자 현지 납부) | ⬜ |
| 배송 기간 공지 | 통관 포함 현실적인 기간 안내 (보통 5~10일) | ⬜ |
| 반품 처리 | 일본→한국 역배송 비용 부담 주체 및 접수 방법 | ⬜ |

### 2-2. 결제
| 항목 | 내용 | 상태 |
|---|---|---|
| Stripe 계약 | JPY 결제 지원 확인 및 계약 완료 | ⬜ |
| 환율 정책 | 고정 환율 vs 실시간 환율 (가격 표시 기준) | ⬜ |
| 수수료 부담 | Stripe 수수료 반영 후 수익성 계산 | ⬜ |

### 2-3. 고객 서비스 (CS)
| 항목 | 내용 | 상태 |
|---|---|---|
| 일본어 CS 담당 | 내부 인력 vs 외주 번역 / AI 보조 | ⬜ |
| CS 채널 | 채널톡 일본어 지원 여부, LINE 공식 계정 개설 여부 | ⬜ |
| 응답 시간 공지 | 시차(1시간) 고려한 응답 가능 시간대 | ⬜ |

### 2-4. 마케팅 / 광고 (일본)
| 항목 | 내용 | 상태 |

### 2-5. 상품 / 가격 (일본)
| 항목 | 내용 | 상태 |
|---|---|---|
| 일본 판매 상품 범위 | 전체 상품 vs 일부 선택 판매 | ⬜ |

## 4. 법적 표시 — 아동복 이커머스 의무사항 (런칭 전 확인)

> 기능이 아니라 **판매 자격** 차원의 항목. 상세는 `docs/launch-checklist.md` 법적 표시 섹션 참조.

| 항목 | 내용 | 상태 |
|---|---|---|
| **KC 인증번호 확보** | 어린이제품 안전특별법 — 판매 페이지에 KC 마크·인증번호 표시 의무. 제품별 인증번호 목록을 개발팀에 전달 필요 (기존 자사몰/제조사에 있을 것) | ⬜ |
| 상품정보제공고시 데이터 | 의류 필수 고지: 소재·치수·제조국·세탁법·품질보증기준·AS책임자. Phase 2 상품 이전 시 데이터에 포함 | ⬜ |
| 에스크로(구매안전서비스) | 가상계좌 수취 시 가입·표시 의무. **토스 MID 계약에 포함되는지 확인** | ⬜ |
| 현금영수증 발급 방식 | 토스 가상계좌 자동발급 옵션 vs Q&A 접수 후 수동 발급. 계약 범위 확인 후 결정 | ⬜ |

## 5. 정책 안건 — 사이즈 교환과 배송비 (아동복 특화)

> 아동복은 사이즈 실패율이 가장 높은 카테고리. 현재 정책(교환 = 반품 후 재구매)에서는
> **8만원 미만 재구매 시 고객이 배송비를 두 번 부담**(반품 회수비 + 재주문 배송비)하게 됨 → CS 불만 예상 지점.

| 항목 | 내용 | 상태 |
|---|---|---|
| 사이즈 교환 보완책 | 예: 사이즈 사유 반품 후 재구매 시 배송비 쿠폰/적립 보전, 또는 현 정책 유지(가격에 반영된 것으로 간주) | ⬜ |
| FAQ·정책 페이지 반영 | 결정 후 FAQ '반품 배송비' 항목과 환불정책 페이지에 명시 | ⬜ |
