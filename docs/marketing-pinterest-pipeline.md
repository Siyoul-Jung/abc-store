# 마케팅 — 핀터레스트 오가닉 자동화 파이프라인 (기획)

> applebuttercollege 무비용 오가닉 트래픽 채널. 메타 광고(월 600~700만, 휘발성)의 보완.
> 엔진/도구 코드·사용법은 [`marketing/README.md`](../marketing/README.md), 전략 배경은 [`docs/team-decisions.md`](team-decisions.md) 참조.

---

## 1. 목표와 원칙

- **목표**: 추가 비용 0으로 검색 기반 신규 유입 채널을 구축. 한국 → 일본 확장.
- **원칙**
  1. **콘텐츠 먼저, 자동화 나중** — 콘텐츠 반응을 검증한 뒤 발행 자동화를 붙인다.
  2. **이미 가진 자산 재활용** — Shopify 상품 이미지·판매 데이터·사이즈 데이터로 만든다.
  3. **담당자 보완, 경쟁 X** — 사람은 감성·화보(인스타 메인), 도구는 데이터·정보형 콘텐츠 + 다채널 확산.
- **현실 기대치**: 핀은 수명이 길어(수개월~수년) **누적 자산**으로 작동. 의미 있는 유입은 **양·꾸준함을 채운 뒤 2~3개월**부터. 즉효는 메타 광고의 영역.

## 2. 채널 역할

| 채널 | 역할 | 발행 | 링크(클릭 유입) |
|---|---|---|---|
| **핀터레스트** | 검색 발견 → 신규 유입 (주력) | 수동 → API 자동(승인 후) | ✅ 핀 목적지 URL |
| **인스타** | 팔로워 도달·인지 (담당자 메인) | 반자동(생성 자동·업로드 수동) | ❌ 피드 불가 → 프로필 링크 |
| 네이버 | 제외 | — | 자동발행 시 저품질 페널티 |

> 우리 도구의 인스타 역할은 **보조 소재 제공**(데이터형 카드)뿐. 메인 운영은 담당자.

## 3. 콘텐츠 템플릿 — 핵심 3유형

엔진(`marketing/card-news-generator.mjs`)은 `decks/` 폴더의 소재 파일을 전부 읽어 카드 PNG + 캡션을 자동 생성한다.
**새 콘텐츠 = `decks/`에 파일 하나 추가**(엔진 수정 불필요).

| # | 유형 | 구조(card type) | 용도 | 상태 |
|---|---|---|---|---|
| **1** | **랭킹/큐레이션** | `cover → rank×N → cta` | 베스트 TOP·시즌 모음("여름 물놀이룩 5") | ✅ 완성 |
| **2** | **단일 상품핀** | `product` (상품 1개 = 핀 1장) | 검색 커버리지·클릭 직행, 물량 | ✅ 템플릿 완성 / ⏳ 상품컷 보강 선행 |
| **3** | **정보형** | (표·가이드) | 사이즈 가이드 등 저장률 높은 정보 | 📋 보류(시기상조) |

> 1번 템플릿이 "랭킹"과 "시즌 큐레이션"을 모두 커버한다(구조 동일, 데이터만 교체).
> 코디룩북(담당자 화보)·컬러 모음(콜라주)은 핵심에서 제외.

### 상품컷 촬영 요청 스펙 (2번 전제)
핀터레스트 규격: **세로 2:3, 1000×1500px 이상**, 상품이 프레임 70~80% 채우게(여백 최소). 상품당 3컷:
1. **누끼 정면컷** — 흰 배경, 여백 최소
2. **디테일 클로즈업** — 원단·패턴·포인트
3. **무드컷** — 플랫레이 또는 착용컷

## 4. 발행 운영 규칙

- **빈도**: 주 3~5장(서로 다른 핀). "양보다 꾸준함". 하루 도배 금지(페널티).
- **fresh pin**: 같은 이미지 재저장은 신선한 핀 아님 → 매번 새 이미지/새 핀.
- **주간 리듬(예시)**: 월=단일상품핀 / 수=시즌 큐레이션 / 금=랭킹·카드뉴스 / (격주)정보형.
- **목적지 링크**: 런칭 전 메이크샵 자사몰(`xcode=012` KIDS). Shopify 런칭 시 도메인·경로 교체. UTM 자동 부착(`utm_source=pinterest`).
- **보드**: 주제별·검색어형 이름("여름 아동복" 등). **Organic > Create Pin만** 사용(Paid 메뉴 = 광고, 사용 안 함).

## 5. 추적

| 층 | 지표 | 도구 | 상태 |
|---|---|---|---|
| 핀터레스트 내 | 노출·저장·**아웃바운드 클릭** | 핀터레스트 Analytics | ✅ 발행만 하면 바로 |

> 1차 검증("핀이 트래픽을 만드나?")은 아웃바운드 클릭만으로 충분. 전환까지 보려면 핀터레스트 태그 삽입.

## 6. 로드맵 (단계)

- **0. 셋업** ✅ — 엔진/소재 분리, 핵심 템플릿 1·2 구현, 캡션·UTM 자동 생성.
- **1. 검증(현재)** — 수동 발행으로 콘텐츠 반응 수집(아웃바운드 클릭). 핀터레스트 API 앱 승인 신청 완료(대기).
- **2. 콘텐츠 양산** — 상품컷 3컷 확보 → 단일 상품핀 양산. 시즌/랭킹 소재 뱅킹. 주 3~5장 지속.
- **3. 발행 자동화** — API 승인 후 `POST /pins`로 수동 과정 대체(엔진 출력물 재사용). 스케줄 발행.
- **4. 전환 추적** — 핀터레스트 태그 삽입(자사몰/Shopify), 전환 측정.
- **5. 일본 확장** — 일본어 deck 추가(텍스트만 교체), 일본 사이트 런칭에 맞춰 발행. 핀터레스트 일본 강세 활용.
