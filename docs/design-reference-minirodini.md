# 디자인 레퍼런스 — Mini Rodini (아동복 Shopify 벤치마크)

> 참조: minirodini.com · 스웨덴 프리미엄 아동복, **Shopify Plus**(TRY Stockholm 구축), 2024 스웨덴 디자인 어워드 GOLD
> 작성: 2026-06-06 · **분석 + abc-store 적용 가이드**
> 함께 보기: `docs/design-rules.md`(우리 규칙), `docs/design-reference-uniqlo.md`(여백 레퍼런스)

---

## 0. 왜 Mini Rodini인가 + 주의

- **같은 카테고리(프리미엄 아동복) + 실제 쇼핑몰 + Shopify 기반** → UNIQLO(채용 사이트)보다 **벤치마크 가치 훨씬 큼**
- 성과: 로딩 300%↑, 모바일 전환 +50%, 해외 매출 +40% → **모바일·디자인이 매출을 만든다**는 증거

> ⚠️ **톤 차이 주의**: Mini Rodini = 대담한 아트 프린트·강한 색·지속가능성 서사.
> applebuttercollege = 따뜻·감각적·미니멀(cream/coral).
> **가져올 것 = 구조·UX 패턴 / 거를 것 = 그들의 강한 비주얼 스타일.** 구조 위에 우리 톤을 입힌다.

## 1. 브랜드 톤: 가져올 것 vs 거를 것

| | Mini Rodini | applebuttercollege | 판단 |
|---|---|---|---|

## 2. 패턴별 분석 → abc-store 매핑

| 패턴 | Mini Rodini | 우리 현황 | 액션 |
|---|---|---|---|
| **공지 바(announcement)** | 상단 세일/공지 바 | 없음 | ✅ **지금 가능** — 세일·배송 공지용 |
| Hero | 풀블리드 + 메시지 | 헤드라인 있음 | 유지 ✅ |
| **카테고리 타일 그리드** | 큰 이미지 타일 7개 + "Shop" | 없음(P2 보류) | ⏸ **카탈로그(태깅) 후** |
| 상품 카드 | 3:4 라이프스타일 사진 | `aspect-[3/4]` ✅ | 구조 OK, **사진을 라이프스타일로**(콘텐츠) |
| 이미지 전략 | 라이프스타일 우세(상황·착장) | 메인컷 위주 | **착장/룩북 컷 확보**(콘텐츠 과제) |
| 브랜드 내러티브 | 홈에 짧은 1섹션 | (제거함 — 목적지 없어서) | 컬렉션 목적지 생기면 재고 ⏸ |
| **푸터** | 4컬럼(About/CS/배송·반품/지속가능) + 소셜 | 사업자정보 위주 | ✅ **지금 가능** — 4컬럼으로 정리 |
| 빈 장바구니 | (베스트 프랙티스: 버튼+추천) | 작은 텍스트 링크만 | ✅ **지금 가능** — 버튼+아이콘+추천 |
| 뉴스레터 가입 | 중간 이메일 수집폼 | 없음 | ⬜ 추후(마케팅 이메일) |
| 멤버십/혜택 | 헤더 멤버십(10%) | 없음 | ⬜ 런칭 후(포인트/쿠폰) |
| 네비 구성 | 타입별(스웨터·드레스…) + 테마 컬렉션 + 시즌 | NEW·KIDS·ADULT·SALE | ⏸ 카탈로그 후 타입/테마 확장 |

## 3. 지금 할 수 있는 것 (카탈로그 무관) ⭐

상품 태깅·룩북 없이도 **바로 개선 가능**한 것들:

1. **빈 장바구니 개선** — 텍스트 링크 → 버튼(알약) + 아이콘 + 따뜻한 문구(+추후 추천상품)
2. **상단 공지 바** — 세일·무료배송·런칭 공지 (전환·정보 전달)
3. **푸터 4컬럼 정리** — About / 고객지원 / 배송·반품 / 회사정보 로 구조화 (현재 사업자정보 위주 → 탐색성↑)
4. **(콘텐츠) 라이프스타일 사진 방향 정하기** — 아이 착장·상황 컷 (촬영/수급 과제, 코드 아님)

## 4. 카탈로그(상품 태깅) 갖춰진 뒤 ⏸

상품이 카테고리로 묶이면 풀리는 것 (= 진짜 임팩트 큰 것):

1. **홈 카테고리 타일 그리드**(P2) — Mini Rodini의 핵심 패턴
2. **테마/시즌 컬렉션** (예: 신상, 시즌 기획)
3. **네비 확장** (타입별/테마)

> 즉 **"카탈로그 정비(상품 태깅·룩북 사진)"가 다음 단계의 최대 잠금해제 열쇠.** 프론트는 준비됐고, 콘텐츠가 병목.

---

## 5. 우선순위 추천

| 순서 | 작업 | 이유 |
|---|---|---|
| 1 | **빈 장바구니 개선** | 가장 작고, 이탈 방지 직접 효과 |
| 2 | **공지 바** | 작고, 세일/공지에 즉시 유용 |
| 3 | **푸터 4컬럼 정리** | 탐색성·신뢰도↑ |
| (병행) | 라이프스타일 사진 수급 | 콘텐츠 과제 — 코드와 별개로 진행 |
| 그 후 | 카테고리 타일(P2)·컬렉션 | **상품 태깅 완료 후** |

> 원칙: **구조는 Mini Rodini, 톤은 applebuttercollege.** 비주얼을 베끼지 말고 패턴을 빌릴 것.
