# 마케팅 — 카드뉴스 콘텐츠 엔진

applebuttercollege 오가닉 마케팅용 **카드뉴스 자동 생성 도구**.
판매 데이터·상품 이미지를 브랜드 톤 카드뉴스(세로 PNG)로 찍어내고, 인스타·핀터레스트에 발행한다.

> ⚠️ 이 폴더는 스토어프론트(`app/`)와 무관한 **로컬 도구**다. Vercel 배포에 포함되지 않는다.
> 생성 산출물(`output/`)은 `.gitignore` 처리 — **엔진 코드만** 버전관리한다.

---

## 빠른 사용법

```bash
# 1) 소재(deck) 수정 → card-news-generator.mjs 안의 deck 객체 편집
# 2) HTML 생성 (미리보기 + 카드별 풀사이즈 페이지)
node marketing/card-news-generator.mjs

# 3) PNG 추출 (설치된 Chrome을 headless로 호출 — npm 패키지 0)
node marketing/export-png.mjs summer-bestsellers

# 4) output/png/*.png 를 인스타·핀터레스트에 업로드
```

- 미리보기: `output/<slug>-<fmt>.html` (브라우저로 열어 확인)
- 최종 PNG: `output/png/<slug>-<fmt>-NN.png`

### 비율(포맷)
`card-news-generator.mjs`의 `FORMATS` 배열에서 제어:
- `4x5` (1080×1350) — **인스타 피드** (기본)
- `2x3` (1080×1620) — **핀터레스트** (주석 해제 시 함께 출력)

> 인스타는 2025년부터 그리드가 4:5 세로. 핀터레스트는 2:3 세로 선호. **정방형(1:1)은 둘 다 비효율** → 세로형 사용.

## 파일 구조

```
marketing/
  card-news-generator.mjs   # 데이터(deck) → 브랜드 톤 HTML. 색·로고·레이아웃 엔진
  export-png.mjs            # HTML → 1080 세로 PNG (Chrome CLI, 무설치)
  README.md                 # 이 문서
  output/                   # 생성 산출물 (gitignore — 재생성 가능)
```

브랜드 자산:
- 로고: `public/logo.png` (레드 스크립트, 워터마크로 자동 삽입)
- 색: 핑크 `#FFEDE9` · 레드 `#CF181C` (인스타 피드에서 추출한 실제 브랜드 값)
- 상품 이미지: Shopify CDN URL (`deck`의 `image` 필드)

## 마케팅 전략 (왜 이렇게 하는가)

### 과제
메타 광고(월 600~700만, 휘발성) 외에 **추가 비용 0**으로 오가닉 채널 구축. 자동화 지향.

### 핵심 원칙
1. **콘텐츠 먼저, 자동화 나중.** 자동화는 배관일 뿐 — 콘텐츠를 검증한 뒤 발행 자동화를 붙인다.
2. **이미 가진 자산 재활용.** 인스타 피드(API)·로고·판매 데이터로 만든다. 새 제작비 0.
3. **담당자와 경쟁 X, 보완.** 사람은 감성·화보, 도구는 *데이터형 콘텐츠*(베스트셀러 랭킹·사이즈 가이드) + 다채널 확산.

### 채널 역할
| 채널 | 발행 | 클릭 링크 | 비용 |
|---|---|---|---|
| **핀터레스트** | 완전 자동(API) | ✅ 핀 목적지 URL | 무료(오가닉) |
| **인스타** | 반자동(생성 자동, 업로드 수동) | ❌ 피드 불가 → 프로필 링크 | 무료 |
| **네이버** | 제외 | — | 자동 발행 시 저품질 페널티 |

> **핀터레스트 = 트래픽 엔진**: 핀마다 목적지 링크 → 실제 유입. 영구 노출, 일본 강세.
> **인스타 = 인지**: 기존 팔로워 도달. 피드는 링크 불가.

### 비용 (핀터레스트)
- 발행(API)·핀 분석·전환 픽셀·UTM 추적 = **전부 무료**. 유료는 광고뿐(안 함).
- 마찰: API 앱 **승인 절차**(돈 X, 시간 O) — 미리 신청해둘 것.

### 타이밍
- 한국 사이트 런칭(토스 승인) 전: **콘텐츠 뱅킹 + 핀터레스트 앱 승인 신청**.
- 본격 발행은 사이트 런칭에 맞춰(트래픽이 도착해도 살 수 있어야 함).
- 일본 사이트 오픈 시 핀터레스트가 이미 데워져 있게.
